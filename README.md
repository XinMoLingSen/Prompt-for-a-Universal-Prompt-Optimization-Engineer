## Usage Tips (to improve stability)
- **Add a trigger prefix**: To more stably guide AI into "optimization mode", it is recommended to add `Optimize Prompt:` at the very beginning of the pasted prompt text.
- Example: `Optimize Prompt: [Enter the prompt you want to optimize here]...`
- Purpose: Some models are more sensitive to specific command words. This operation can reduce the risk of AI skipping the Q&A session directly.
